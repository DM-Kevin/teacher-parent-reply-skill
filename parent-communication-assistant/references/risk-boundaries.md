# 高风险沟通边界

## 进入高风险模式的信号

- 学生受伤、疑似欺凌或严重纪律事件；
- 家长投诉教师或学校、威胁曝光或追责；
- 要求教师先承认责任、保证赔偿或承诺特殊处理；
- 事实来源互相冲突，涉及监控、证人或正式调查；
- 涉及疑似心理健康问题、自伤或他伤风险。

## 处理合同

1. 先确认学生当前安全和是否需要就医或紧急支持。
2. 只陈述已确认事实，明确哪些经过仍在核实。
3. 记录时间、地点、已采取措施和沟通情况，保留相关材料。
4. 按学校流程同步班主任、年级负责人或管理人员。
5. 责任和费用由学校依据核实结果及流程处理；教师不提前认责或保证结果。
6. 微信只完成关心、事实状态、核实安排和下次反馈时间，复杂争议转正式沟通。

## 可直接发送的结构

```text
理解家长着急
→ 说明孩子当前状态和已经采取的措施
→ 区分已知事实与待核实部分
→ 告知已报备／将按学校流程处理
→ 约定下一次反馈
```

安全边界不等于把调查、责任、费用和所有流程一次塞进长消息。优先写本轮必须知道的内容。

## 能力边界

本 Skill 不进行心理诊断，不调查或裁定事实，不决定责任和赔偿，也不替代学校制度、专业医疗建议或紧急处置。出现即时人身风险时，优先联系学校负责人和当地紧急服务。
