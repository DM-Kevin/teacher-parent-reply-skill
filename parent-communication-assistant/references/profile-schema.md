# 档案字段规范

## 存储原则

- 真实档案位于 Skill 目录外；默认建议使用用户文档目录下的`家长沟通档案/`。
- 设置文件只保存档案根目录和结构版本，不保存学生、家长或教师内容。
- 原始截图和完整聊天默认不落盘。
- 身份证号、家庭住址、电话号码等无关敏感信息不得写入。
- AI 先展示预览；教师明确确认后才调用写入命令。

## 教师表达偏好

`教师档案/表达偏好.md`固定使用：

```markdown
# 表达偏好
## 常用称呼
## 回复长度
## 语气与直接程度
## 语气词与表情
## 开场与收尾
## 避免表达
```

初始化可分析 3～5 组截图或 8～15 条教师消息。先确认哪一侧属于教师，只提炼教师表达。生成一条模仿测试消息，教师确认“像我”后再保存。

`已确认表达样本.md`最多保留 10 条代表样本。一次修改只视为本次需要；两次相似修改提示可能偏好；三次相似且均经确认后，才建议更新长期偏好。

## 学生索引

固定六列：编号、姓名、年级、班级、目录、最近更新。总索引不保存家长特点。姓名重复时展示年级、班级和编号供教师选择。

## 当前概况

```markdown
# 当前概况
## 基本信息
## 已确认的长期表现
## 已采取的支持措施
## 家长关注点与沟通偏好
## 尚未解决的问题
## 最近一次沟通结论
## 信息更新时间
```

使用可观察描述：

- 推荐：“家长对作业必要性持保留态度，偏好简短、具体的沟通。”
- 不写：“家长油盐不进、只爱听好话。”

“敏感、懒、态度差、不讲理”等标签只能转成待教师确认的具体行为或表达偏好。

## 沟通记录

```markdown
# 沟通记录
## 日期与渠道
## 本次问题
## 已确认事实
## 家长核心关注
## 教师实际回应
## 达成共识
## 待跟进事项
## 是否更新长期概况
```

只保存必要摘要。`日期与渠道`使用`- 日期：YYYY-MM-DD`和`- 渠道：微信／电话／面谈`；`本次问题`使用`- 主题：...`；`是否更新长期概况`使用且只使用一次`- 是否更新：是`或`- 是否更新：否`，为“是”时另写拟更新内容并单独确认。教师实际回应应以最终发送版本为准；不知道是否修改时，在结束阶段统一询问一次。

## 按需读取顺序

1. 读取精简的`教师档案/表达偏好.md`；
2. 读取`学生档案/学生索引.md`；
3. 命中后读取该生`当前概况.md`；
4. 只有本次问题涉及历史事件时，才检索该生相关`沟通记录/`文件。

不得遍历或读取其他学生目录，也不默认读取目标学生的全部历史记录。
